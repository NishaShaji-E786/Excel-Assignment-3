# Excel-Assignment-3
Healthcare Data Analysis and Insights  Assignment-3
🏥 Turning Healthcare Data into Meaningful Insights with Excel! 📊

The goal of this project was to transform raw healthcare data into meaningful insights through data analysis and interactive visualizations.

🔍 What I worked on:

✅ Data Cleaning – Improving data quality and consistency.

✅ Data Transformation – Structuring and preparing data for analysis.

✅ Data Exploration – Exploring healthcare records to identify patterns and trends.

✅ Analysis & Visualization – Converting data into meaningful visual insights.

✅ Pie & Donut Chart Analysis – Understanding category-wise distributions and proportions.

✅ Line & Scatter chart Analysis – Visualized trends, explored relationships between healthcare variables, and identified patterns through Line Charts and Scatter Plots

📊 Key Highlights:

Interactive Excel Dashboard.
Visual representation of healthcare data.
Meaningful data summaries and insights.

💡 Key Takeaway:

This project helped me strengthen my skills in Microsoft Excel, data analytics, exploratory data analysis, and data visualization while understanding how raw data can be transformed into actionable insights.
